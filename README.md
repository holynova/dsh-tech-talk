# DeepSeek Harness (`dsh`) 技术分享演示文稿

面向程序员同事的 **DeepSeek Harness (`dsh`)** 20 分钟概念与原理分享网页（衔接 20 分钟自研插件 Demo）。

## 在线预览

- GitHub Pages：https://holynova.github.io/dsh-tech-talk/

## 演讲快捷键

| 快捷键 | 功能 |
|---|---|
| `←` / `→` / `Space` | 上一页 / 下一页 |
| `1` - `9`, `0` | 快速跳转对应页 |
| `G` | 打开幻灯片总览 |
| `N` | 切换底部讲者提示抽屉 |
| `Q` | 打开高频 Q&A 速查 |
| `T` | 切换亮色 / 暗色主题 |
| `F` | 进入 / 退出全屏 |
| 点击右上角计时器 | 开始 / 暂停 20 分钟倒计时（双击重置） |
